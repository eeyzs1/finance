分散投资与相关系数

预计 18 分钟难度：进阶入门前置：第 1 课

第 1 课我们学会用期望收益和标准差给资产"打分"。这一课把两份资产放进同一个篮子：你会发现收益只是简单的加权平均，风险却能"打折"——而折扣的大小，取决于一个叫相关系数（correlation coefficient）的数字。理解了它，你就理解了为什么分散投资（diversification）被称为金融里唯一的免费午餐。

一、组合的期望收益：老老实实的加权平均

把资金按权重 w 买入资产 A，按 (1−w) 买入资产 B，组合的期望收益没有任何花样：

μp = w × μA + (1 − w) × μB
算例：A 的期望收益 μA = 8%，B 的 μB = 4%，各投 50%，则 μp = 0.5×8% + 0.5×4% = 4% + 2% = 6%。期望收益永远是权重的加权平均，不会因为"放在一起"而变多或变少。

二、组合的风险：不是加权平均

风险的算法完全不同。组合标准差的公式是：

σp = √( w²σA² + (1−w)²σB² + 2·w·(1−w)·ρ·σA·σB )
直觉版：根号里的前两项是两种资产各自贡献的风险；第三项是关键——它背着相关系数 ρ。当 ρ 为负数时，第三项整体变成"减项"，直接从总风险里扣掉一块；ρ 越接近 −1，扣得越狠。

如果风险也像收益一样做加权平均，那么 50% A（σA=15%）加 50% B（σB=5%）的风险应该是 0.5×15% + 0.5×5% = 10%。但只要 ρ 小于 +1，上面的公式算出的结果一定比 10% 低。省下来的那一块，就是分散的馈赠。

三、相关系数 ρ：分散的万能旋钮

ρ 的取值范围是 −1 到 +1，它决定了折扣的力度。还是用 A（σA=15%）、B（σB=5%）各投 50% 的例子，看三种典型情形：

ρ = +1：完全同涨同跌

两种资产像连体婴，第三项全额加上：σp 恰好等于加权平均 10%。买了两只"动作一样"的资产，等于什么都没分散——白忙一场。

ρ = 0：互不相干

第三项整项消失：σp = √(0.25×0.0225 + 0.25×0.0025) = √0.00625 ≈ 7.9%。只是"不相关"，就已经比 10% 低了 2.1 个百分点。

ρ = −1：完全对冲

A 涨时 B 恰好等比例跌，第三项变成减项：σp = √(0.005625 + 0.000625 − 0.00375) = √0.0025 = 5%。若把权重调成 25% A + 75% B（15%×0.25 = 5%×0.75），甚至可以把风险压到 0。

现实中的股票很少能完全对冲：同一市场里的股票 ρ 大多落在 0.2–0.4 之间。好消息是——这已经足够大幅降险（下面就用 0.3 实际试算）。

唯一的免费午餐

上例中组合的期望收益始终是 6%，一分没少；风险却从加权平均的 10% 打折到 7.9%（ρ=0）甚至 5%（ρ=−1）。不牺牲任何期望收益就降低了风险——所以有人说"分散投资是金融里唯一的免费午餐"。你付出的不是收益，只是"不把宝全押在一只资产上"的纪律。

四、有效前沿：把权重拧到最优

把权重 w 从 0 慢慢拧到 1，每个 w 都在"风险—收益"平面上落下一个点 (σp, μp)，所有的点连成一条子弹形曲线。曲线的上半段——同样风险下收益最高的那些组合——叫有效前沿（efficient frontier）。理性投资者只会在这一段上挑选自己的组合。

另一条思路是"加只数"：单只股票独有的意外（产品失败、官司、高管出事）叫特质风险（idiosyncratic risk），持有的个数越多，它们互相抵消得越干净。经验上，20–30 只股票已能分散掉大部分特质风险，之后再增只数，降险效果递减。指数基金一次买入几百只股票，等于把这道工序直接外包给一篮子。

两资产组合模拟器

固定 μA=8%、σA=15%，μB=4%、σB=5%。绿色曲线是权重从 0 扫到 1（步进 0.02）得到的全部组合；金点是当前权重；最靠左的绿点是数值扫描出的最小方差组合。默认 ρ=0.3、w=50% 时：σp = √(0.25×0.0225 + 0.25×0.0025 + 2×0.25×0.3×0.15×0.05) = √(0.005625 + 0.000625 + 0.001125) = √0.007375 ≈ 8.6%。

试一试

① 把 ρ 拉到 −1：曲线弯成子弹形，最小方差组合贴到最左；② 把 ρ 拉到 +1：曲线拉成直线，分散彻底失效；③ 固定 ρ=0.3，把权重从全仓 A 慢慢左移：收益降一点、风险降一大截——这就是免费午餐的形状。

✓ 本课收获
