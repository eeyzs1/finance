期权定价的直觉

预计 15 分钟难度：进阶前置：本分支第 2 课

上一课我们画出了期权到期时的盈亏图，但还没回答最关键的问题：今天这张期权到底值多少钱？这一课先用直觉回答"什么让期权更贵"，再用一步二叉树把一个完整算例逐步算透——全程只需要高中数学；最后看一眼诺贝尔奖级别的 BS 模型到底"想"的是什么。

期权价格的两块拼图：回顾与深化

第 2 课的结论：权利金（premium） = 内在价值（intrinsic value） + 时间价值（time value）。内在价值一眼能算，真正的难题是时间价值：可能性凭什么值钱、值多少？

先给结论：波动率越高、剩余时间越长，期权越贵。原因是期权收益的天生不对称——上行不封顶，下行有地板（最差不过归零作废）。波动只会把标的推向两端的极端，而期权只从一端受益：涨疯了大赚，跌狠了也只亏权利金。波动越剧烈，"涨疯"的那一半期望越大，期权就越贵。

数字实验：同样的期望，4 倍的价格

A、B 两只股票，一年后的价格与概率：

股票悲观情景（50%）乐观情景（50%）期望价格行权价 100 看涨的期望收益
A（低波动）901101000.5×0 + 0.5×10 = 5 元
B（高波动）601401000.5×0 + 0.5×40 = 20 元

验算：A 的看涨到期收益，悲观时 max(90−100,0)=0，乐观时 max(110−100,0)=10，期望 = 5 元；B 的悲观时 max(60−100,0)=0（注意：跌得再深，收益也封底在 0），乐观时 max(140−100,0)=40，期望 = 20 元。两只股票的期望价格一模一样，波动更大的 B 让同一张期权贵了 4 倍。时间的作用同理：剩余时间越长，标的能"走"得越远，两端的极端越夸张——期权只吃上涨那一端的红利。

顺带一句波动率微笑（volatility smile）：把同一到期日各行权价期权的隐含波动率（implied volatility）画出来，理论上应是水平线，实际常呈"微笑"的 U 形——市场为极端行情索要的溢价，比模型想的更贪婪。

一步二叉树：把定价算到分毫不差

直觉之后来点精确的。二叉树模型（binomial tree model）假设：股票现价 100 元，一年后只有两种可能——上涨到 120（涨幅 u = 1.2）或下跌到 80（d = 0.8）。求行权价 K = 100 的看涨期权今天的公允价格，无风险利率 r = 5%。

第一步：写出两个未来状态的期权收益。

  • 上行：股价 100×1.2 = 120，收益 C上行 = max(120−100, 0) = 20 元；
  • 下行：股价 100×0.8 = 80，收益 C下行 = max(80−100, 0) = 0 元。

第二步：算风险中性概率 p。我们不预测真实涨跌概率，而是问：怎样一组概率能让股票的期望涨幅恰好等于无风险利率？

p = 1 + r − du − d = 1.05 − 0.801.20 − 0.80 = 0.250.40 = 0.625
验算：p×120 + (1−p)×80 = 0.625×120 + 0.375×80 = 75 + 30 = 105 = 100×1.05 ✓ 这组"概率"下，股票期望恰好按无风险利率增长。无套利条件：必须 d < 1+r < u，否则 p 跑出 [0,1]，说明参数本身存在套利空间。

第三步：用 p 算期望收益，再按无风险利率折现。

C = p×C上行 + (1−p)×C下行1 + r = 0.625×20 + 0.375×01.05 = 12.51.05 ≈ 11.90 元

逐步验算：期望收益 = 0.625×20 + 0.375×0 = 12.5 + 0 = 12.5 元；折现 = 12.5 ÷ 1.05 = 11.904… ≈ 11.90 元。这张期权今天就该卖 11.90 元左右。

⇄ 交叉验算：复制组合（另一种算法，结果相同）

今天买 0.5 股股票、同时按 5% 借入 38.10 元：一年后上行值 0.5×120 − 38.10×1.05 = 60 − 40 = 20 元；下行值 0.5×80 − 40 = 40 − 40 = 0 元——与期权收益完全一致。这份复制品今天的成本 = 0.5×100 − 38.10 = 11.90 元。两种算法殊途同归，这正是无套利定价的力量：期权 = 一个自制的迷你组合。

注意看：把 u 从 1.2 拖到 1.5（分歧更大），期权公允价从 11.90 一路上涨——这就是"波动率是期权的心跳"的算术版。

📈 波动率与期权价值 · 分歧越大，权利金越贵

固定行权价 100、无风险利率 5%、现价 100，让上涨幅度 u = 1+m 与下跌幅度 d = 1−m 同步从 0.06 增大到 0.5（m 再小时 u = 1+m ≤ 1+r = 1.05，违反无套利条件 d < 1+r < u，定价失效）：期权价值单调递增——上涨无限、下跌封底的不对称，把波动全部转化成了期望收益。

风险中性概率：不是预测，而是计价尺

很多初学者卡在 p 上："凭什么用 0.625 而不是我认为的上涨概率？"答案是：p 根本不是对未来的预测，而是一把计价尺。定价的逻辑是"复制品值多少，期权就值多少"（见上方的交叉验算）：既然期权可以被"股票 + 无风险资产"精确复制，它的价格就只取决于这把尺，与你我怎么看涨看跌无关。真实概率当然影响股票本身的价格，但那已经体现在现价 100 元里了。这个"用无风险利率校准世界"的视角，叫风险中性（risk-neutral）定价——衍生品金融学最反直觉、也最优美的一步。

BS 模型：把树变成连续的世界

把二叉树的"一步"切得越来越细——一年拆成一万个瞬间，涨跌两种状态就逼近连续的价格路径。1973 年，Black、Scholes 与 Morton 沿这条路给出了 closed-form 答案：布莱克-斯科尔斯模型（Black-Scholes model）。它的思想只有一句话：期权可以被"标的股票 + 无风险资产"动态复制，复制的成本就是期权的价格——正是上面 Δ=0.5 股 + 借入 38.10 元算例的连续版。公式里含正态分布函数，不要求掌握，记住"复制"两个字你就拿到了它的灵魂；想要完整公式，见 Investopedia：Black-Scholes Model（英文）。这一工作拿了 1997 年诺贝尔经济学奖，也撑起了此后半个世纪的衍生品行业。

✓ 本课收获
  • 期权价格 = 内在价值 + 时间价值；波动越大、时间越长，时间价值越高；
  • 不对称性（上行不封顶、下行有地板）是期权"吃波动"的根源——同样期望下高波动股票的期权贵 4 倍；
  • 一步二叉树三步走：两个状态的收益 → p = (1+r−d)/(u−d) → 期望收益 ÷ (1+r)；算例得 11.90 元，与复制组合法一致；
  • BS 模型的灵魂是复制：期权 = 标的 + 无风险资产拼出来的自制组合。
