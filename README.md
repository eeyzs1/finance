### 相邻与交叉领域（不单独设文件夹）

这些领域与主分支深度交叉，教程中会在对应分支里涉及：

- **公共金融 / 财政学**（Public Finance）：政府收支、税收与公债 → 与货币银行学（02）联动；
- **金融数学 / 数理金融**（Mathematical Finance）：随机过程与定价的严格数学 → 融入投资学（04）与金融工程（05）；
- **量化交易**（Quantitative Trading）：算法与数据驱动的交易实践 → 投资学（04）+ 金融工程（05）；
- **房地产金融**（Real Estate Finance）：按揭、REITs 与资产证券化 → 个人理财（10）+ 金融市场（01）；
- **可持续金融 / ESG**（Sustainable Finance）：绿色债券、ESG 投资 → 投资学（04）+ 金融科技（11）；
- **金融监管与合规**（Regulation & Compliance）：巴塞尔协议、监管科技 → 风险管理（06）+ 货币银行学（02）；
- **金融史**（Financial History）：从美第奇家族到布雷顿森林 → 贯穿各分支案例。

   01 金融市场与机构  →  02 货币银行学

   05 衍生品与金融工程  →  06 风险管理  →  07 国际金融

   10 个人理财  →  09 保险与精算  →  11 金融科技

## 三、这套教程怎么用（教学法说明）

本课程按 [teach 教学法](https://skills.sh/mattpocock/skills/teach)组织，核心原则：

1. **每课只讲一个点**：课程短小、聚焦，学完有一个能带走的具体收获（写在每个分支每课的"本课收获"卡片里）；
2. **先直觉后公式**：概念用交互式动画、模拟器建立直觉（拖动滑块观察变化），公式只作直觉的凝练；
3. **检索练习**：每课末尾有随堂测验——凭记忆作答、即时反馈。答完隔几天回来"重新测验"一次，短时记忆才会变成长期记忆；
4. **可信来源**：每个知识点尽量附真实来源链接（Investopedia、维基百科、央行与 IMF 等），每课推荐一篇首选阅读材料；
5. **术语统一**：全课程术语表见 [`reference/glossary.html`](reference/glossary.html)，正文首次出现的术语带虚线下划线，悬停可看释义；
6. **随时提问**：课程是静态 HTML，但你的 AI 助教是活的——读到任何不懂的地方，回到对话里直接问。

## 四、环境与离线使用

- 所有课程页面为**自包含 HTML + 共享本地脚本**，不依赖任何 CDN 或网络字体，直接双击用浏览器打开即可（推荐 Chrome / Edge）；
- 交互组件（图表、模拟器、测验）全部使用原生 JavaScript + SVG，无需安装任何东西；
- **学习进度**：每课测验的成绩与日期自动保存在浏览器 localStorage（仅本机、离线、不上传）；再次打开该课时会显示"上次成绩"，总目录页会汇总进度并列出超过 3 天未重测的课（配合间隔复习）。清除浏览器数据会清空进度；
- 页面打印友好（Ctrl+P），可导出 PDF 复习。
